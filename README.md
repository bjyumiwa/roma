# Vienna Speak Coach — ウィーン英語発表練習アプリ

提供された「ウィーン動画１(2).pptx」をもとに、16枚のスライド画像と発表用ノートの **英語・カタカナ発音・日本語訳** を収録した、Android / PC用Webアプリです。

- GitHub Pagesで動く静的サイトです。サーバーのプログラム・APIキー・有料サービスは不要です。
- 英語のお手本音声は **Android / Chrome の音声読み上げ (Speech Synthesis)** を使います。外部の音声ファイルを配布しているわけではありません。
- 自分の音声はスマホのマイクで録音し、その端末で再生・保存できます（MediaRecorder）。録音内容はサイトへ送信しません。**ページを再読み込みすると録音一覧は消えます**。残したい音声は「録音をスマホに保存」で保存してください。
- Chromeが対応していれば、英語の音声認識による文字起こし（SpeechRecognition）が使えます。ただし**発音採点ではありません**。ブラウザーの認識サービスへ音声が送信される場合があり、インターネット接続が必要になる場合があります。
- 練習済みのスライド番号と表示・速度設定は、その端末のブラウザーに保存します。
- 一度読み込んだページは、一部のブラウザーではオフラインでも開けます。ただし音声読み上げ・音声認識・インストール機能の可否は端末やOS設定によります。

## GitHub Pages に置く方法（パソコン）

1. このZIPファイルを**解凍**します。
2. GitHub (https://github.com/) で `New repository` を押し、例えば `vienna-speak-coach` という名前の新しいリポジトリを作ります。
3. 作ったリポジトリで `Add file` → `Upload files` を開きます。**解凍したフォルダーの中身**（`index.html` / `app.js` / `data.js` / `style.css` / `slides` フォルダー / `icons` フォルダー / `manifest.webmanifest` / `service-worker.js` / この README）をアップロードし、`Commit changes` を押します。ZIPファイルそのものをアップロードしてもWebアプリにはなりません。
4. リポジトリの `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` を選択し、`Branch: main` と `Folder: / (root)` を選択して `Save` します。
5. デプロイが完了したら `https://あなたのGitHubユーザー名.github.io/vienna-speak-coach/` にアクセスします。リポジトリ名が違う場合は、その名前に変更してください。公開までは数分かかることがあります。

## Android で使う方法

1. Androidの **Google Chrome** で、上記の GitHub Pages のURLを開きます。
2. 「スライド全体を聞く」で端末の英語音声を再生します。速度は `0.60×～1.25×` で変えられます。
3. 英文をタップし「選んだ1文」を押すと、その文だけ繰り返し聞けます。カタカナ発音と日本語訳は非表示にもできます。
4. 「録音開始」でマイクへのアクセスを許可します。自分で英文を読んだら「録音終了」を押し、その場で再生できます。
5. 必要なら「録音をスマホに保存」を押します。ファイルはブラウザーが対応する形式（通常 `.webm`）です。
6. Chromeのメニュー `︙` → `ホーム画面に追加` または `アプリをインストール` を選ぶと、アプリのように起動できます（表示される文言は端末によります）。

※Chromeのマイク機能には **HTTPS** が必要です。GitHub PagesはHTTPSに対応しています。Androidのファイルアプリから`index.html`を直接開く使い方では、マイクなどの一部機能が動かないことがあります。

## 使う前に確認したいこと

**公開に注意**：無料の公開GitHubリポジトリにアップロードすると、スライド内の名前・図・生徒作品などの画像も一般に閲覧できるようになります。アップロード前に公開して問題ないか必ず確認してください。発表資料の公開を望まない場合は、公開型GitHub Pagesを使わず、アクセス制限可能なホスティング方法を検討してください。

**発表時間**：16枚のスライドで指定されていた `SUGGESTED PACE` の合計は **585秒（9分45秒）** です。会議からの指示が「10分超、25分以下」であるため、現在の目安では **最低16秒以上** 足りません。実際の録画は10分より余裕を持って行い、上限25分も超えないようにしてください。

**研究内容**：アプリは元の発表ノートを原則そのまま音読用に表示しています。数値・引用・研究上の主張を新規に検証したり、訂正したりしたものではありません。

## ファイルの構成

```text
index.html           Web画面
style.css            スマホ対応デザイン
app.js               英語読み上げ、録音、文字起こし、タイマー
 data.js             PowerPoint発表者ノートから抽出した原稿
manifest.webmanifest ホーム画面への追加設定
service-worker.js    オフライン用キャッシュ
icons/               アイコン2種類
slides/              スライド画像16枚（WebP）
README.md            この説明書
```

## 更新方法

英語原稿を直す場合は、`data.js` の対応スライドの `english` / `kana` / `japanese` を編集します。音声は変更された英語原稿を読み上げます。サイトのファイルを更新したら、`service-worker.js` の `CACHE` を `vienna-speak-coach-v2` 等に変更すると、更新版のキャッシュへ切り替わります。

## 対応の目安

- Android: Google Chrome 推奨
- Windows / Mac: Chrome / Edge などでお手本再生とタイマーは利用可能（マイクと音声認識は端末・ブラウザー依存）
- ネイティブAPKではなく、GitHub Pagesで動く **PWA（ホーム画面に追加できるWebアプリ）** です。
