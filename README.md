# Vienna UK Reader – Android・GitHub Pages用

ウィーン発表PowerPointの発表者ノートを基に、英国の学会発表で自然に聞こえる話し言葉へ一部整えた16スライド・72文の「英語／英国発音に近いカタカナ／日本語訳」を収録したシンプルな読み上げアプリです。録音や音声認識はありません。

## GitHubへのアップロード

1. 同梱ZIPを展開（解凍）します。
2. GitHubで新しいリポジトリ（例：`vienna-uk-reader`）を作ります。
3. `Add file → Upload files` で、**ZIPではなく展開した中身**の `index.html`, `app.js`, `data.js`, `style.css`, `manifest.webmanifest`, `service-worker.js`, `icons` フォルダーをすべてアップロードし、`Commit changes` を押します。
4. `Settings → Pages` を開き、`Deploy from a branch`、`main`、`/(root)` を選び `Save` します。
5. 公開された `https://あなたのユーザー名.github.io/vienna-uk-reader/` をAndroidのChromeで開きます。URLはリポジトリ名で変わります。反映まで数分かかる場合があります。
6. AndroidのChromeメニュー `︙ → ホーム画面に追加` で、アプリのように起動できます。

## 使い方

- 初めはスライド1です。**「このスライドを読み上げ」**で英語だけを読みます。
- 1文ごとの丸い ▶ ボタンで、その英文だけ読みます。
- 英文のすぐ下に、**英国英語を意識したカタカナ**と**日本語訳**を表示します。
- 画面下に常時表示される **「次へ →」** ボタンを**1回押すだけ**でスライド2以降へ進みます。次のスライドは先頭から表示されます。反対側の「← 前へ」で戻れます。画面全体をタップしても意図せず進みません。
- 再生速度を「ゆっくり／練習／通常／速め」から変更できます。
- 英語の再生にはAndroidブラウザの読み上げ機能を使用します。`en-GB` 音声が見つかった場合はその英国英語音声を使います。見つからない場合は言語だけ`en-GB`を指定して再生するため、端末によって英国アクセントが保証されません。端末のテキスト読み上げ設定で English (United Kingdom) を追加してください。
- カタカナでは実際の英語の子音・母音・強勢を完全には表せません。音声を優先してください。

## プライバシー

- このZIPには**スライド画像や生徒作品の画像は含まれません**。文字原稿のみです。
- ただし、発表原稿の内容はGitHub Pages上では公開されます。原稿自体を非公開にしたい場合は公開型GitHub Pagesを使用しないでください。
- APIキーや外部音声合成サービスは使用しません。マイクへのアクセスも不要です。
- オフライン再表示はキャッシュの状況によります。音声再生の可否は端末に依存します。

## ファイル

`index.html`（画面） / `style.css`（見た目） / `app.js`（英国英語の音声・次へ） / `data.js`（16スライド・72文の三言語表示） / `manifest.webmanifest`（ホーム画面へ追加） / `service-worker.js`（キャッシュ） / `icons`（アイコン）

## 今回の変更

- Androidで長いセリフを読んでいても、画面下に「次へ →」が固定表示されます。
- 1回タップで次のスライドに進み、画面が先頭に戻ります。
- 読み上げ中にスライドを変えると音声は停止します。
- 前の版が出続けるときはAndroidのChromeでページを再読み込みしてください。更新したキャッシュ名で新しいファイルが保存されます。
