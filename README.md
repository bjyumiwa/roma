# VCAH 2026 英語発表練習 — 共著 We 版 v5

元のWAIE式アプリの機能と、全24枚のスライド画像、端末の音声エンジンを使わない英国式合成MP3音声を保ちました。

共著として述べる研究目的・判断・提案に関する10文を I から We に修正し、カタカナ表示と内蔵MP3も同時に更新しました。

- 個人の自己紹介「I teach art」はそのままです。
- 生徒の発言「I ...」という引用や「CSRIのI（Iterate）」は変えていません。
- 元のスライド本文は引用などのため、絵は変更していません。PowerPointの発表者ノートに英語修正を反映しています。

## GitHub Pages の更新
この `index.html` だけを既存リポジトリのルートへアップロードして、以前の `index.html` を置き換え、Commit changes します。
画面のバージョン表記が「共著We版 v5」に変われば、新しいファイルが開けています。キャッシュが残る場合は `?v=5` を公開URLの末尾に付けてください。

## 音声
「UK英語」欄で「英国式合成音声（MP3）」を選択し、各文または音声テストをタップしてください。
音声はネイティブ話者の録音ではなく英国式の機械合成音声です。
