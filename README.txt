Vienna UK Reader | VCAH 2026

このフォルダーをそのままGitHub Pagesなどの静的ホスティングにアップロードしてください。
index.htmlを開くと、16枚分の画像・英語原稿・カタカナ・日本語訳を確認できます。

ファイル構成
  index.html                  : アプリ本体
  data.js                     : 16枚/112文の英語・UK発音カタカナ・日本語訳
  slides.js                   : スライド画像パス
  app.js                      : 音声再生・切り替え・タイマーなど
  style.css                   : スタイル
  manifest.webmanifest        : PWA情報
  icons/                     : アイコン
  slide-images/              : 16枚のスライド画像

使い方
  1. GitHubリポジトリにZIPを展開して、すべてのファイルとフォルダーを追加
  2. Settings > Pages > Deploy from a branch > main / (root) を選択
  3. 表示URLにアクセスして練習

注意
  * 読み上げはブラウザの Speech Synthesis API と端末の音声に依存します。
  * en-GB を指定しますが、端末に英国英語音声がない場合は別の声になる場合があります。
  * iOSなどでは音声操作にユーザーによるタップ操作が必要です。
  * ウェブ上に公開する場合、スライド画像が閲覧可能になるので公開範囲にご注意ください。
  * ZIPには学生の実名を含む個別回答原票は収録しません。
  * 12枚目は使用有無と採用度を区別する図に差し替えています。
  * 「生成0回」はその日の画像生成回数であり、AIの累計利用量ではありません。
