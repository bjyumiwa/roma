# Vienna 2026 英語練習アプリ（WAIEと同じ操作）

WAIE2026で使用した `index_mobile_fixed.html` を元に、Vienna用のスライド画像・英語台本・カタカナ・日本語を入れた版です。スライド画像は24枚です（付録2枚を含む）。

## GitHub Pagesでの設置
1. このZIPを展開します。
2. `index.html`、`.nojekyll`、`slides` フォルダのすべてを新しいGitHubリポジトリのルートにアップロードします。
3. Settings → Pages → Deploy from a branch → `main` / `(root)` を選び、Saveします。
4. 数分後にGitHub Pages URLをAndroidのChromeで開きます。

## 操作
- 本文の英文をタップ：1文読み上げ
- 上の「▶ この文」「↻ 3回練習」「▶ 続けて再生」：WAIE方式の練習
- 英語音声：UKが端末の音声一覧に出れば選択可能。出ない場合は端末標準音声を使ってください。
- カタカナは参考表記であり、実際のUK発音を完全に表現できません。
- 自分の英語練習は「マイク録音」ではなく、声を出して繰り返す方式です。
