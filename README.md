# Vienna English Speaking Studio — 24 slides

添付の `1019v3.pptx` の24枚と発表者ノートに基づくスマホ用英語発表練習アプリです。データは1つのHTMLファイルに全て含まれています。

## GitHub Pagesへの設置

1. `vienna_english_practice.html` をダウンロードして、ファイル名を **`index.html`** に変更します。
2. GitHubで新しいリポジトリを作成します（公開設定にご注意ください）。
3. `index.html` をルートにアップロードしてCommitします。
4. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save。
5. 表示された GitHub Pages のURLをスマホで開きます。「ホーム画面に追加」でアプリのように使えます。

## 主な機能

- スライド24枚を画像表示。22枚が本編、23-24枚が付録です。
- 発表者ノートの推奨英語台本 / アカデミック版 / 日本語訳。
- カタカナ発音目安（自動変換のため、正確な発音記号ではありません）。
- 英国英語 en-GB の音声読み上げ。英国英語の声が端末にない場合は警告表示。
- 速度調整 0.6～1.4倍、全文・1文ずつ再生、1文の3回リピート。
- 端末のマイクを使用した練習音声の録音・再生（サーバー送信はしません）。
- 練習済みチェック、スライド番号の保存（ブラウザーのローカルストレージ）。

## 使用上の注意

- 音声の声質は端末・ブラウザーにインストールされた音声に依存します。`en-GB` の選択は英国アクセントの完全保証ではありません。英国英語がない場合は端末の音声機能追加をご検討ください。
- 録音には HTTPS（GitHub Pages）とマイク権限が必要です。音声はブラウザーでのみ扱い、録音したものはページを閉じると消えます。
- GitHub Pagesは原則として公開サイトです。画像、原稿、所属表記などの公開可否を確認してください。
- PowerPointの発表者ノートから抽出しました。日本語は「推奨英語」の逐語訳ではなく、ノート原文そのままです。
- HTMLは外部ライブラリや外部APIを使っていません。基本画面はオフラインでも表示できますが、録音等のブラウザー機能は動作条件があります。
