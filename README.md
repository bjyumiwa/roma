# ウィーン英語発表練習（WAIE式・画像表示版 v4）

`index.html` にスライド24枚の画像と、英国式合成音声のMP3 206文をすべて内蔵しています。
アプリの一番上にスライド画像が出ます。「前の絵」「次の絵」でスライドを切り替えられます。
下にスクロールすると英文・カタカナ・日本語訳と、1文ごとの音声再生があります。

GitHub Pages: 既存リポジトリの **ルートにある `index.html` をこのファイルで上書き** → Commit changes → GitHub Pagesの更新を待ち、Android Chromeで `?v=4` を末尾に付けた公開URLを開き直します。
例: `https://username.github.io/reponame/?v=4`

画面上の「（画像表示版 v4）」が見えなければ、GitHub Pagesに古いコードが表示されている可能性があります。

スライドと音声を別ファイルで置く必要はありません。スライドは元の添付1019v3.pptxの表示イメージです。
